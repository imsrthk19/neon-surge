# ⚡ NEON SURGE

> *The addictive neon lane-dodge survival game. How long can you last?*

---

## 🎮 About the Game

**NEON SURGE** is a browser-based endless survival game where you pilot a neon spacecraft through incoming waves of obstacles. Dodge left and right to survive, chain dodges for combos, collect power-ups, and outlast your personal best.

**Core mechanic:** Switch between 3 lanes to dodge obstacles as the game speed constantly increases. Miss one hit and it's game over — but the "ONE MORE TRY" feeling keeps you coming back.

## 🚀 How to Run Locally

### Option 1 – Just Open in Browser (Quickest)
1. Navigate to the `NeonSurge` folder
2. Double-click `index.html`
3. Play immediately!

### Option 2 – Live Server (Recommended for development)
```bash
# If you have Node.js installed:
npx serve .

# Or with Python:
python -m http.server 8080
```
Then visit `http://localhost:8080`

## 🌐 Deploy for Free

### GitHub Pages
1. Create a new GitHub repo (e.g., `neon-surge`)
2. Upload all 3 files: `index.html`, `style.css`, `game.js`
3. Go to **Settings → Pages**
4. Set source to `main` branch / `root`
5. Your game is live at `https://yourusername.github.io/neon-surge`

### Netlify (Even Easier)
1. Go to [netlify.com/drop](https://app.netlify.com/drop)
2. Drag the `NeonSurge` folder onto the page
3. Instantly live with a shareable URL!

## ✨ Features

### Gameplay
- 🚀 **3-Lane dodge system** with smooth animations
- 📈 **Progressive difficulty** — speed ramps continuously
- 🎯 **Combo system** — chain dodges for score multipliers
- 💥 **4 obstacle types**: Wall, Spike, Laser, Barrier
- 🎁 **4 power-ups**: Shield, Slow-Mo, 2X Score, Magnet

### Retention
- 🔥 **Daily streaks** — play every day to build your streak
- 🏆 **12 achievements** to unlock
- 🎨 **4 themes** (Neon, Cyber, Flame🔒, Void🔒) — unlock by scoring
- 📊 **Local leaderboard** with top 20 scores
- 🌍 **Simulated global leaderboard**
- 📅 **Daily challenge** — new challenge every day

### Social / Viral
- 📤 **Native share** (mobile)
- 🐦 **Twitter/X share** button
- 💬 **WhatsApp share** button
- 🔗 **Copy score text** for any platform
- ⚔️ **Challenge a friend** feature
- 🏅 **Score badges** (Survivor → Legendary)

### Tech
- Pure **HTML5 + CSS3 + Vanilla JS** — zero dependencies
- **Canvas API** for game rendering
- **Web Audio API** for procedural sound effects
- **LocalStorage** for all persistence
- **Responsive** — works on mobile, tablet, desktop
